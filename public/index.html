Демо-счета брокеров

Внутренний виртуальный счёт агента и счета OANDA — отдельные счета. Здесь доступно подключение для проверки баланса, позиций и ордеров; сделки агента пока не отправляются в OANDA.

1. Создайте OANDA Practice

Выберите свою страну и создайте демо-счёт. Доступность v20 API зависит от подразделения OANDA. Для этой интеграции нужен именно v20 Practice, не MT5.

Регистрация: официальная инструкция ↗ · Кабинет OANDA в новом окне ↗

В кабинете создайте Personal Access Token через управление API. Токен подключает программу; для входа в кабинет используются ваш логин и пароль OANDA. Пароль кабинета здесь не хранится.
