# Облачная версия валютного агента
URL: https://forex-paper-agent.trading-agent.workers.dev

Workers + D1, без туннеля и без зависимости от включённого ПК. Cron */5 * * * * UTC. Анализ по очереди EURUSD и GBPUSD, каждой пары не чаще раза в 4 часа. Выходные пропускаются. Ключи AES-GCM в D1, мастер-ключ в Worker Secrets. Пароль панели — отдельный Worker Secret. Локальная зашифрованная резервная копия доступа: LocalAppData/TradingAgent/cloud-access.enc. Просмотр: ../show_cloud_access.vbs.

Вкладки: обзор/журнал, API-ключи/сроки, четыре синтетических сценария и проверка реальных котировок Yahoo из Cloudflare. Сценарии используют настоящий облачный код риска/исполнения, без AI, сеть не вызывают, счёт не меняют. Это не оценка прибыльности.

Облачная версия — порт, а не бит-в-бит копия Python: сохранены промпты аналитика/критика, пары, интервалы, размеры, комиссия, стоп и просадка. Упрощены новостные источники (FXStreet, ФРС, BoE); внеочередной AI-анализ по резкому движению пока не перенесён. Отдельный счёт $10 000, старая статистика не смешивается. Анализ изначально выключен. FRED-ключ хранится как резерв; стратегия его пока не использует. Quotes older than 30 minutes block execution. GET check-data разрешает показать устаревшие выходные котировки, помечая stale=true.

Бюджет API: расчёт по usage $4/$20 за миллион, лимит $90 на календарный месяц UTC, перед запросом резервируется $0.75; при сетевой ошибке резерв не возвращается. Это не чтение фактического баланса Anthropic. Бесплатный Cloudflare Free имеет 10ms CPU на invocation; отслеживайте 1102, платный план автоматически не включается. Вызовы Anthropic оплачиваются отдельно.

D1 lease 10 минут защищает от параллельных циклов; после каждого изменения счёт сохраняется. Состояние и события разделены: при сбое между сохранением и журналом баланс может обновиться до записи события. trades в state содержит исполнения. Stop-loss при гэпе может исполниться хуже порога. Реконнект для брокерского WebSocket отсутствует: это бумажный агент с опросом Yahoo.

Развёртывание: node node_modules/wrangler/bin/wrangler.js deploy. D1 schema.sql. Secret ADMIN_PASSWORD и ENCRYPTION_KEY (32 bytes base64). Не коммитьте секреты. Тесты: node --test tests/*.test.js. После проверки облачного cron остановите локальное расписание, чтобы не платить дважды.
